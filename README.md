# Nutrient dynamics following 50 years of reduced loading in the large and shallow Lake Arresø
This repository is dedicated to the paper ["**Nutrient dynamics following 50 years of reduced loading in the large and shallow Lake Arresø**"](https://doi.org/10.1007/s10750-025-05952-9) by Sand-Jensen, K., Sø, J.S. and Kragh, T. published in Hydrobiologia.

## Data and code 
The repository consists of all data and code used in the project. While the data can be downloaded from the [Miljøportalen](https://danmarksarealinformation.miljoeportal.dk/) and [Vandportalen](https://vandportalen.dk/).
